Kata

Translation that runs on your computer. Your text never leaves your browser.

Kata is a Chrome extension that translates with small open-source AI models running inside the browser. There is no server, no account and no tracking. After a one-time download per language, it works offline.

What it does

  • Translate a selection: right-click → Translate, or Alt+Shift+T. A card appears next to the text.
  • Translate what you type: in any text box, Alt+Shift+Y replaces your text with the translation.
  • Quick translate from the toolbar popup.
  • 25 languages, including English, Indonesian, Chinese, Japanese, Korean, Vietnamese, Thai, Hindi, Arabic, Spanish, French, German and Russian.
  • Download only what you need (about 110 MB per language direction) and delete models any time.

Privacy

Kata collects nothing. The only network requests are model downloads from Hugging Face, and those never include your text. Read the full privacy policy.

Open source

The source code is on GitHub under the MIT License. Questions and bug reports go to the issue tracker.

Translation models: Opus-MT by the Language Technology Research Group at the University of Helsinki, licensed CC BY 4.0, in ONNX form via Xenova on Hugging Face.
